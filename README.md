# moments2tg

Пересылает **Moments (朋友圈) выбранных друзей из WeChat в Telegram-канал**: текст, фото, видео,
ссылки и геометки, по желанию с лайками и комментариями. Работает на вашем компьютере
через локальный HTTP API приложения [WeFlow](https://github.com/hicccc77/WeFlow).
Управляется через веб-панель с мастером настройки.

```
WeChat (десктоп) ──► локальная база ──► WeFlow (расшифровка, HTTP API)
                                             │
                                        moments2tg  ──► Telegram Bot API ──► ваш канал
                                   (панель 127.0.0.1:8765)
```

Ничего не отправляется ни на какие серверы, кроме Telegram. WeChat и WeFlow скрипт только читает.

---

## Что понадобится

| | |
|---|---|
| **Компьютер** | Windows 10/11, macOS (Apple Silicon) или Linux x64, где запущен десктопный WeChat с вашим аккаунтом |
| **WeFlow** | установлен и подключён к базе WeChat ([как получить](#weflow)) |
| **Python** | 3.10 или новее |
| **Telegram** | бот (создаётся в [@BotFather](https://t.me/BotFather)) и канал, где бот — администратор |

## Что движок — Alpha

moments2tg берёт Moments не напрямую, а через локальный HTTP API приложения
**[Alpha](https://github.com/xunchahaha/alpha-releases)** (преемник WeFlow от тех же авторов).
Alpha умеет расшифровывать базу актуального WeChat (4.x) сам, поэтому отдельные модули,
ключи и т.п. не нужны. moments2tg одинаково работает и с Alpha, и с WeFlow — что из них
запущено и отдаёт API, к тому и подключается.

## Установка одной командой

После того как получили проект (ниже по ОС), одна команда скачает **официальный** установщик
Alpha, проверит его SHA-256 и запустит:

```bash
start.bat --setup        # Windows
./start.sh --setup       # macOS / Linux
```

Alpha — стороннее приложение, в репозиторий оно не входит; скрипт тянет его с официального
релиза и проверяет контрольную сумму. Если Alpha уже установлен — шаг пропускается.
Один раз откройте Alpha, подключите WeChat (ключ он найдёт сам) и включите его HTTP API
(设置 → 接口与集成 → 本机 HTTP API: задайте токен → 保存并启动). Дальше API поднимается
автоматически, а всё остальное ведёт панель moments2tg.

## Быстрый старт

### Windows

1. Установите Python с [python.org](https://www.python.org/downloads/). В установщике **отметьте «Add python.exe to PATH»**.
2. Скачайте проект: зелёная кнопка **Code → Download ZIP** на GitHub (и распакуйте) или
   ```bash
   git clone https://github.com/Pirnazar/moments2tg.git
   ```
3. Поставьте Alpha: `start.bat --setup` (или установите Alpha сами).
4. Запустите панель: дважды щёлкните **`start.bat`**.

При первом запуске скрипт создаст окружение `.venv` и поставит зависимости (около минуты),
затем откроет панель в браузере, и сразу запустится мастер настройки.

### macOS

1. Python: `brew install python` или установщик с [python.org](https://www.python.org/downloads/).
2. Скачайте проект:
   ```bash
   git clone https://github.com/Pirnazar/moments2tg.git
   cd moments2tg
   ```
3. Запустите:
   ```bash
   ./start.sh
   ```
   Можно и двойным щелчком по **`start.command`** в Finder. В первый раз macOS может не дать
   его открыть: щёлкните правой кнопкой → «Открыть» → «Открыть». Если проект скачан ZIP-архивом,
   сначала выполните `chmod +x start.sh start.command`.

### Linux

```bash
sudo apt install python3 python3-venv git      # Debian/Ubuntu; Fedora: sudo dnf install python3 git
git clone https://github.com/Pirnazar/moments2tg.git
cd moments2tg
./start.sh
```

Панель откроется в браузере по адресу http://127.0.0.1:8765. Если браузер не открылся сам,
откройте этот адрес вручную.

## Мастер настройки

Мастер открывается сам, пока настройка не завершена. Его можно вызвать снова кнопкой
**«Мастер настройки»** в шапке панели.

1. **WeFlow.** Кнопка «Настроить WeFlow автоматически» включает HTTP API в WeFlow, задаёт новый токен,
   прописывает его в moments2tg, включает запуск WeFlow вместе с системой (свёрнутым в трей)
   и перезапускает WeFlow. Если WeFlow не найден или не настроен, мастер подскажет, что сделать.
2. **Telegram.** Вставьте токен бота и нажмите «Проверить». Добавьте бота **администратором канала**
   с правом публикации, опубликуйте в канале любое сообщение и нажмите «Найти мои каналы».
   Мастер проверит, что бот может публиковать, и предложит отправить тестовое сообщение.
3. **Аккаунты.** Отметьте друзей, чьи Moments пересылать. Список приходит из WeFlow, есть поиск.
4. **Запуск.** Галочки «Запускать опрос вместе с панелью», «Не публиковать старые посты» и
   **«Запускать панель при входе в систему»**. После этого пересылка работает сама.

## Панель управления

| Вкладка | Что там |
|---|---|
| верх панели | статус, кнопки «Запустить / Остановить», «Проверить сейчас», «Тест Telegram», «Тест WeFlow» |
| **Аккаунты** | все друзья с Moments, поиск, выбор галочкой, подпись в канале, имя для поиска в WeChat |
| **WeFlow** | запущен ли WeFlow, отвечает ли API, совпадает ли токен; запуск, перезапуск и остановка WeFlow; его настройки (API, порт, токен, автозапуск, сворачивание в трей); **защита от удаления Moments**; диагностика |
| **Настройки** | токены, канал, прокси, интервалы, обновление лент (Windows), автозапуск панели |
| **Отправленные** | что ушло в канал за сессию |
| **Журнал** | живой лог |

Изменения применяются со следующего прохода, перезапуск не нужен. Панель слушает только
`127.0.0.1`: с других компьютеров и с чужих сайтов к ней не обратиться.

## WeFlow

moments2tg получает данные из WeFlow, поэтому WeFlow должен быть установлен, запущен
и подключён к базе WeChat.

> **Важно.** WeFlow не содержит модуль чтения и расшифровки базы WeChat: его подключают
> отдельно в настройках WeFlow (подробности в
> [docs/third-party-components.md](https://github.com/hicccc77/WeFlow/blob/main/docs/third-party-components.md)).
> Если в самом WeFlow открываются ваши Moments, всё готово.

### Сборка WeFlow из исходников

Готовых релизов в репозитории WeFlow сейчас нет, поэтому установщик собирается самостоятельно.
Нужны [Node.js](https://nodejs.org/) 20+ и git. Собирать нужно на той же ОС, для которой нужен установщик.

```bash
git clone https://github.com/hicccc77/WeFlow.git
cd WeFlow
npm ci --force
```

Для npm 11 и новее нужно разрешить install-скрипты нативных пакетов (в более старых npm шаг не нужен):

```bash
npm install-scripts approve koffi ffmpeg-static esbuild @hicccc77/electron-liquid-glass
npm rebuild koffi ffmpeg-static esbuild @hicccc77/electron-liquid-glass
```

Сборка:

```bash
npm run build
```

Результат появится в папке `release/`:

| ОС | Файл |
|---|---|
| Windows | `WeFlow-<версия>-Setup.exe` |
| macOS | `WeFlow-<версия>-arm64.dmg` |
| Linux | `WeFlow-<версия>.AppImage` или `.tar.gz` |

`--force` нужен потому, что у одной из зависимостей устаревшие peer-требования к React, а
`npm ci --force` ставит дерево зависимостей ровно по `package-lock.json` авторов.

После установки откройте WeFlow, пройдите первичную настройку (подключение к базе WeChat),
а дальше всё остальное сделает мастер moments2tg.

### Где moments2tg ищет WeFlow

| ОС | Приложение | Файл настроек |
|---|---|---|
| Windows | `%LOCALAPPDATA%\Programs\WeFlow\weflow.exe` | `%APPDATA%\WeFlow\WeFlow-config.json` |
| macOS | `/Applications/WeFlow.app` | `~/Library/Application Support/WeFlow/WeFlow-config.json` |
| Linux | `~/Applications/WeFlow*.AppImage`, `/opt/WeFlow/weflow` | `~/.config/WeFlow/WeFlow-config.json` |

Если у вас пути другие, укажите их на вкладке **WeFlow** (или в мастере на первом шаге).

Как панель меняет настройки WeFlow: WeFlow держит их в памяти, пока запущен. Поэтому панель
закрывает WeFlow, меняет только нужные поля (перед первой правкой делает копию
`WeFlow-config.json.moments2tg.bak`) и запускает WeFlow снова. Если в WeFlow включена блокировка
паролем, после перезапуска разблокируйте его вручную, иначе API не поднимется.

## Автозапуск

Включается галочкой «Запускать панель при входе в систему» (в мастере или на вкладке «Настройки»).
Права администратора не нужны. Создаётся:

| ОС | Что создаётся |
|---|---|
| Windows | `moments2tg.cmd` в папке автозагрузки (`shell:startup`) |
| macOS | LaunchAgent `~/Library/LaunchAgents/com.moments2tg.panel.plist` |
| Linux | `~/.config/autostart/moments2tg.desktop` (автозапуск рабочего стола) |

Чтобы пересылка работала без вас, при входе в систему должны запускаться WeChat и WeFlow.
WeFlow можно включить на вкладке **WeFlow** (галочка «Запускать WeFlow вместе с системой»),
WeChat в его собственных настройках.

## Обновление лент через pywechat (только Windows)

Десктопный WeChat скачивает Moments друга, только когда эту ленту открывают. Если новые
посты появляются в WeFlow с задержкой, включите **Настройки → Обновление лент через pywechat**.
Тогда панель периодически сама откроет ленты выбранных друзей в WeChat через
[pywechat](https://github.com/Hello-Mr-Crab/pywechat) (UI-автоматизация). Пакет ставится
кнопкой «Установить pywechat» там же.

- На время обновления скрипт **двигает мышь и нажимает клавиши**. Нужен разблокированный рабочий стол.
  Если вы работаете за компьютером, обновление откладывается (настройка «Не мешать, если активны N сек»).
- Нужен WeChat 4.1.6+ и аккаунт с видимым UI-деревом. Подробности в README pywechat.
- Имя друга для поиска берётся из заметки или ника; если поиск находит не того, задайте имя на вкладке «Аккаунты».

## Командная строка

Все команды работают и через `start.bat` / `./start.sh` (без аргументов открывается панель):

```bash
./start.sh --panel --no-browser    # панель без открытия браузера
./start.sh --once                  # один проход и выход
./start.sh                         # = --panel
./start.sh --list                  # список друзей с Moments (wxid и имя)
./start.sh --test                  # тестовое сообщение в канал
./start.sh --refresh-test          # один раз открыть ленты друзей через pywechat (Windows)
```

Без панели, в фоне: `./start.sh --panel --no-browser` с включённой галочкой
«Запускать опрос вместе с панелью», либо цикл без панели (запускать из папки проекта):

```bash
.venv/bin/python moments2tg.py           # macOS / Linux
.venv\Scripts\python.exe moments2tg.py   # Windows
```

## Файлы

| Файл | Что это |
|---|---|
| `config.json` | ваши настройки и токены (создаётся панелью; в git не попадает) |
| `config.example.json` | пример всех настроек |
| `state.json` | id уже отправленных постов, чтобы не было повторов |
| `moments2tg.log` | журнал |
| `.venv/` | окружение Python, создаётся `start`-скриптом |

Токены можно не хранить в файле, а задать переменными окружения `WEFLOW_TOKEN`, `TG_BOT_TOKEN`, `TG_CHAT_ID`.
Если удалить `state.json`, скрипт начнёт с нуля.

## Частые вопросы

**Новые посты появляются с задержкой или не появляются.**
WeFlow видит только то, что десктопный WeChat уже скачал. Откройте ленту друга в WeChat
или включите [обновление лент](#обновление-лент-через-pywechat-только-windows) (Windows).

**В панели «WeFlow: нет связи».**
WeFlow не запущен, в нём выключен API или он заблокирован паролем. Откройте вкладку
**WeFlow**: там видно, что именно не так, и есть кнопка запуска.

**«Telegram: неверный токен бота» / «Бот не может публиковать».**
Проверьте токен в @BotFather. Бот должен быть администратором канала с правом
«Публикация сообщений».

**Telegram заблокирован у провайдера.**
Укажите прокси в **Настройки → Telegram → Прокси**, например `socks5://127.0.0.1:1080`
(для socks: `.venv/bin/python -m pip install "requests[socks]"`).

**Как обновить moments2tg?**
`git pull` в папке проекта (или скачайте ZIP заново, сохранив `config.json` и `state.json`),
затем перезапустите `start`-скрипт: новые зависимости поставятся сами.

## Ограничения

- Видны только посты, которые ваш аккаунт WeChat вообще может видеть (приватность друзей, «последние 3 дня» и т. п.).
- Bot API принимает файлы до 50 МБ; фото больше 10 МБ уходят документом. Что не удалось загрузить, помечается в посте.
- Если отправка не удалась (например, нет сети), пост повторится в следующем проходе. Порядок постов сохраняется.
